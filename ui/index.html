Sub-Microsecond In-Process Engine 
use tapirus::{Connection, Result};

fn main() -> Result<()> {
    // Single encrypted disk file (< 4 MB idle memory)
    let db = Connection::open("production.tapir")?;

    // Relational SQL table with native 1536-D vector embedding
    db.execute("CREATE TABLE memory (id INT PRIMARY KEY, content TEXT, vector VECTOR(1536));")?;
    db.execute("INSERT INTO memory VALUES (1, 'Sovereign AI', [0.12, -0.45, ...]);")?;

    // Sub-microsecond GraphRAG & vector similarity traversal
    let matches = db.query("SELECT id, content FROM memory ORDER BY VECTOR_COSINE(vector, [...]) LIMIT 5;")?;
    println!("Matches: {:?}", matches);
    Ok(())
}

Kill the "Frankenstack".

Stop gluing four disparate databases across fragile network sockets. TapirusDB collapses your vector store, graph database, SQL engine, and document repository into one atomic in-process runtime.

Quad-Model Convergence

Four Engines. One Atomic File.

Execute relational queries, semantic vector similarity, relationship traversals, and schemaless lookups without ever serializing data across network boundaries.

1. ANSI SQL-92 Relational Core

Full SQL engine with ACID transactions, composite primary keys, foreign constraints, and B+Tree clustered indexing.

SELECT * FROM agents WHERE status = 'active' ORDER BY score DESC;

2. Native HNSW Vector Search

Sub-microsecond approximate nearest neighbors. Supports Cosine, Euclidean, and Dot Product, accelerated by SIMD AVX-512 & NEON.

VECTOR NEAR [0.12, 0.45, -0.67] TOP 5 METRIC cosine;

3. openCypher & GraphRAG

CSR topology graph indexing for associative memory and multi-hop relationships. Built-in Reciprocal Rank Fusion (RRF).

MATCH (p:Agent)-[r:CONTROLS]->(t:Target) RETURN p.name, t.state;

4. Schemaless JSON Document Store

Store arbitrary nested JSON payloads with automated sub-millisecond document indexing and schema flexibility.

db.collection("telemetry").insert_one({"device": "drone_alpha"});
