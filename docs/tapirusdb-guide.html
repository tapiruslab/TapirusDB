Database kecil yang duduk dekat dengan aplikasi.

TapirusDB ialah database Rust embedded untuk menyimpan data relasi, dokumen, graf, vektor dan memori AI dalam fail .tapir yang sama. Halaman ini menerangkan cara menggunakannya dan bagaimana lapisannya berhubung.

Nota pembacaan

Anggap TapirusDB sebagai komponen dalam proses aplikasi. Ia bukan database teragih dan bukan pengganti automatik SQLite, PostgreSQL, atau servis vector khusus. Semak query yang disokong dan uji workload sebenar anda.

Rustengine utama dalam proses aplikasi
.tapirfail data + WAL untuk perubahan
SQL + AIrelasi, vektor, graf, dokumen, memori
Local-firstSDK native, WASM dan Studio

Cara guna

Pilih satu pintu masuk mengikut aplikasi anda. Contoh di bawah menggunakan API sebenar yang diterangkan oleh repo.

Rust

Database relasi paling ringkas

Buka fail, buat jadual, guna parameter untuk input pengguna, kemudian tutup connection.

use tapirus::{Connection, Result};

fn main() -> Result<()> {
    let db = Connection::open("notes.tapir")?;
    db.execute("CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT NOT NULL)")?;
    db.execute("INSERT INTO notes (id, body) VALUES (1, 'Semak recovery')")?;
    let rows = db.query("SELECT id, body FROM notes")?;
    println!("{rows:?}");
    db.close()?;
    Ok(())
}
Node.js

Memori untuk aplikasi AI

Simpan teks dan namespace, kemudian cari semula sumber yang relevan untuk prompt aplikasi.

const { open } = require('tapirus');
const db = open('assistant.tapir');

db.storeMemory({
  content: 'Maintenance setiap 500 jam.',
  namespace: 'manuals'
});

const sources = db.searchMemories({
  query: 'maintenance interval',
  namespace: 'manuals', limit: 5
});
console.log(sources);
db.close();
CLI / Rust

Pilih edisi

Gunakan edisi Lite, Document, Graph atau Vector jika anda mahu entry point yang lebih kecil. Edisi berkongsi format fail .tapir, tetapi API dan keupayaan tetap perlu disemak.

cargo build --release -p tapirus \
  --no-default-features \
  --features lite --bin tapirus-lite
Studio

Jalankan workbench

Studio ialah UI React/TypeScript untuk memeriksa SQL, dokumen, graf dan vektor semasa pembangunan. Ia companion interface, bukan pengganti pengesahan database produksi.

cd studio
npm ci
npm run dev

Seni bina

Aliran asas bergerak dari aplikasi ke API native/WASM, masuk ke core Rust, kemudian ke storage dan indeks yang berkaitan.

Gambaran konseptual: semak source dan ujian untuk menjadikan keputusan reka bentuk ini sebagai bukti pada workload tertentu.

Storage

Fail + WAL

Pager mengurus halaman fail .tapir; mutasi melalui write-ahead log sebelum recovery dan reopen. Header fail menyimpan metadata format, freelist dan nombor WAL.

Retrieval

Memori AI

Carian boleh menggabungkan BM25, similarity vektor, recency dan importance. Embedding datang daripada model pilihan aplikasi; TapirusDB tidak memanggil model luar secara automatik.

Browser

WASM berasingan

WASM workspace boleh membuka/menyimpan snapshot native melalui IndexedDB. Salinan browser tidak sama dengan React Studio dan tidak menggantikan native storage untuk semua workload.

TAP Model Forge

Aliran latihan tempatan dalam Studio: dataset domain → student open-weight → adapter LoRA yang boleh diaudit.

Import dataset

Gunakan JSONL, NDJSON, JSON atau CSV. Medan diterima ialah instruction/output, prompt/response atau input/target. Minimum dua contoh diperlukan.

Pilih student dan cache model

Model asas dimuat turun ke studio/model_cache/. Latihan menggunakan cache tempatan dan menetapkan mod Hugging Face offline.

Teacher pilihan

Teacher OpenAI-compatible hanya digunakan jika diaktifkan dan diberi consent. Output terpilih dihantar ke API luar; credential tidak ditulis ke manifest atau bundle.

Latihan sebenar

Backend melancarkan train_lora.py sebagai subprocess. Progress, train loss dan held-out loss datang daripada proses latihan sebenar.

Terbitkan bundle

Output disahkan sebelum menjadi .tap-model.zip. Manifest menyimpan checksum dataset, konfigurasi latihan, model asas dan metrik yang tersedia.

Aliran offline: selepas base model dan adapter wujud dalam cache tempatan, inferens boleh berjalan tanpa internet atau teacher API. Adapter LoRA tetap memerlukan base model yang dinyatakan dalam manifest.

Perkara yang perlu dijaga

Ini ialah batasan reka bentuk dan status bukti yang penting sebelum digunakan pada data kritikal.

TopikMaksud praktikal
SQLTapirusDB menyokong subset SQL yang didokumenkan. Ia bukan drop-in SQLite atau tuntutan full SQL conformance.
ConcurrencyConnectionPool::acquire() mengklon connection yang sama; ia bukan pool sesi database bebas. Gunakan SessionDatabase jika transaksi memerlukan pemilik berasingan.
DurabilityWAL dan recovery mempunyai ujian terpilih. Uji crash, reopen, backup/restore dan filesystem sasaran anda sendiri.
SecurityEncryption halaman adalah pilihan. Semak key handling, binding C ABI, host process dan threat model deployment.
PerformanceJangan gunakan angka sejarah sebagai janji produk. Ukur hardware, dataset, compiler flags dan tetapan durability yang sama dengan deployment.
Formal modelFail TLA+ menerangkan transisi WAL terpilih; repo tidak mendakwa ada refinement proof atau formal verification terhadap binary Rust.
