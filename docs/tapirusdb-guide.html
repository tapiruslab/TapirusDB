Rust

Transaksi MVCC & SQL berparameter

Gunakan SessionDatabase untuk transaksi penulis eksklusif dan snapshot_reader() untuk pembaca MVCC tanpa sekatan.

use tapirus::{Config, Result, SessionDatabase, Value};

fn main() -> Result<()> {
    let db = SessionDatabase::open_with_config(
        "notes.tapir",
        Config { encryption_key: Some("kunci-rahsia".into()), ..Default::default() },
    )?;
    let writer = db.session()?;
    writer.execute("CREATE TABLE IF NOT EXISTS notes (id INTEGER PRIMARY KEY, body TEXT NOT NULL)")?;
    writer.execute_with_params("INSERT INTO notes VALUES (?, ?)", &[Value::Integer(1), Value::Text("Disulitkan & Pantas".into())])?;
    let rows = db.snapshot_reader()?.query("SELECT id, body FROM notes")?;
    println!("{rows:?}");
    writer.close()?; db.close()?;
    Ok(())
}
Node.js / AI

Memori AI Hibrid (HNSW + BM25 + RRF)

Simpan dokumen dengan pengasingan namespace/sesi dan cari semula sumber menggunakan HNSW ditala bersama BM25 dan petikan sumber.

const { open } = require('tapirus');
const db = open('assistant.tapir');

db.storeMemory({
  content: 'Penukaran penapis setiap 500 jam operasi.',
  namespace: 'manuals',
  tags: ['source:engineering']
});

const sources = db.searchMemories({
  query: 'penukaran penapis',
  namespace: 'manuals',
  limit: 5
});
console.log(sources);
db.close();
Daemon HTTPS + MCP

Pelayan TLS 1.3 Natif & RBAC AST

Jalankan tapirus serve dengan sijil TLS Rustls natif, RBAC mengikut jadual pada peringkat AST SQL, dan token namespace memori AI.

tapirus serve assistant.tapir \
  --tls-cert cert.pem --tls-key key.pem \
  --api-key "$ADMIN_KEY" \
  --api-key-role "$READER=readonly:notes" \
  --api-key-namespace "$AGENT=manuals"
Browser / WASM

Enjin Safe-Rust dalam Pelayar

Jalankan SQL berparameter, carian memori AI, dan vault terenkripsi XChaCha20-Poly1305 terus dalam WebAssembly menggunakan @tapirus/wasm.

import init, { TapirusWasm } from '@tapirus/wasm';
await init();
const db = TapirusWasm.new_encrypted('passphrase');
db.execute("CREATE TABLE vault (id INTEGER PRIMARY KEY, note TEXT)");
const bytes = db.export_bytes();

Seni bina

Setiap lapisan dibina dengan satu fail teras .tapir, WAL tahan ranap, pemampatan LZ4 telus, serta enjin indeks berbilang model.

Seni bina bersepadu TapirusDB: daripada adapter pelbagai bahasa dan TLS natif hingga ke Pager AEAD, SWMR WAL dan indeks HNSW/BM25/CSR.

Storage

Fail + WAL + LZ4

Pager 4 KiB mengurus B+Tree, pemampatan LZ4 Safe-Rust telus, penyulitan XChaCha20-Poly1305 per halaman, dan SWMR WAL yang disemak dengan model TLA+ TLC2.

AI Memory

TPMEM001 & Neural MCP

Rekod memori disimpan dalam format binari padat TPMEM001 bersama snapshot indeks HNSW ber-CRC32, serta sokongan pembekal embedding Ollama/OpenAI dalam tapirus mcp.

Keserasian

SQLite C ABI & Edisi

Menyokong FOREIGN KEY, CHECK, DEFAULT, TRIGGER, indeks komposit, FTS5, serta lapisan C ABI sqlite3_* (sqlite3_bind_*, sqlite3_exec) dalam tapirus-ffi.

TAP Model Forge

Aliran latihan tempatan dalam Studio: dataset domain → student open-weight → adapter LoRA yang boleh diaudit.

Import dataset

Gunakan JSONL, NDJSON, JSON atau CSV. Medan diterima ialah instruction/output, prompt/response atau input/target.

Pilih student dan cache model

Model asas dimuat turun ke studio/model_cache/. Latihan menggunakan cache tempatan dengan mod Hugging Face offline.

Teacher pilihan

Teacher OpenAI-compatible hanya digunakan apabila diaktifkan dengan persetujuan eksplisit; credential tidak pernah ditulis ke manifest atau bundle.

Latihan sebenar

Backend melancarkan train_lora.py sebagai subproses bagi menghasilkan metrik latihan dan held-out loss sebenar.

Terbitkan bundle

Output disahkan sebelum menjadi .tap-model.zip lengkap dengan checksum dataset, konfigurasi latihan, model asas dan metrik.

Aliran offline penuh: Setelah base model dan adapter wujud dalam cache tempatan, inferens berjalan sepenuhnya secara tempatan tanpa akses internet atau API luar.
