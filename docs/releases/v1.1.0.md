# TapirusDB v1.1.0

This minor release delivers a major SQL batch ingestion speedup that beats SQLite 3.46.0 WAL on `batch_1000_with_commit`, adds `WITH RECURSIVE` CTEs, `UNION` / `UNION ALL`, inline arithmetic/concatenation expressions, partial indexes (`CREATE INDEX ... WHERE ...`), a lightweight `@tapirus/wasm-lite` browser runtime (`1,225,332` bytes / `422,554` bytes gzip), unified Lakehouse/Excel (`calamine` + `rust_xlsxwriter`) + SQLite compatibility (`tapirus convert`), and hardened security (`rustls` TLS 1.2/1.3, AST SQL RBAC, Page-1 AEAD AAD binding, `Zeroize`, Browser encrypted `.tapir`, and MSRV Rust `1.88`).

## Highlights

- **Batch 1,000 SQL INSERT Optimization (`4.67 ms` vs SQLite `5.77 ms`):** Added `Connection::execute_insert_plan` shared parameterized fast path, reusable executor scratch buffers (`insert_scratch_buf` / `insert_scratch_vals`), direct pre-validated B+Tree leaf insertion inside transactions without redundant 4 KiB savepoint page cloning, and zero-overhead event queueing when no realtime subscribers are attached.
- **Recursive CTEs, `UNION [ALL]`, Expressions & Partial Indexes:**
  - `WITH [RECURSIVE] cte(cols) AS (seed UNION [ALL] recursive_step)` with cycle-safe `UNION` deduplication and depth cap (`10,000` iterations).
  - Arithmetic (`+`, `-`, `*`, `/`, `%`) and string concatenation (`||`) infix expressions with standard operator precedence and parentheses.
  - `CREATE [UNIQUE] INDEX ... ON table(col) WHERE predicate` partial index maintenance, filtered uniqueness enforcement, query planner residual filtering, and persistence across reopen.
- **Ultra-Lightweight Browser Runtime (`@tapirus/wasm-lite`):** Added `lite` feature and `--lite` WASM build (`crates/tapirus-wasm/pkg-lite`), reducing raw WASM payload by ~39% (`~1.23 MiB` raw / `~423 KB` gzip) while retaining full SQL, bound parameters, `WITH RECURSIVE`, partial indexes, ChaCha20-Poly1305 encryption (`new_encrypted`, `import_encrypted_bytes`), and `.tapir` interchange.
- **Security, TLS, AST RBAC & External Audit Scope:** Native `rustls` TLS 1.2/1.3 (`--tls-cert`, `--tls-key`), AST-enforced `--api-key-role` SQL authorization covering `WITH RECURSIVE` & `UNION`, Page-1 immutable header Poly1305 AAD binding, `Zeroize` secret scrubbing, MSRV `1.88` dependency hygiene (`0` active production OSV advisories), TLA+ TLC2 crash-safety gate, and an updated external audit scope brief (`docs/security/EXTERNAL_AUDIT_RFP.md`).
- **Lakehouse & Spreadsheet Interoperability:** Query `.parquet`, `.csv.gz`, `.tsv`, `.jsonl`, and Hive partitions (`read_parquet`), plus bidirectional conversion across `.xlsx`/`.xls`/`.ods`/`.xlsb`, `.sqlite`, `.pdf`, `.md`, and `.tapir`.

## Release Checks

All checks run cleanly against the tagged release commit (`cargo fmt --check`, strict `clippy -D warnings`, full `cargo test --locked --workspace --offline`, edition profile checks, `tapirus-micro`, WASM quad + lite checks, release-readiness benchmark parity, and OSV dependency screening).

TapirusDB supports a documented SQL subset and selected vector, graph, document, and AI Memory APIs. This release includes first-party security testing and a third-party audit RFP (`docs/security/EXTERNAL_AUDIT_RFP.md`); an independent firm-signed audit PDF is published under `docs/security/reports/` once commissioned externally.
