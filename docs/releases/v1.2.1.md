# TapirusDB v1.2.1

`v1.2.1` completes the Phase 8–9 SQLite compatibility, query optimizer, and security-hardening release line after `v1.2.0` (`docs/releases/v1.2.0.md` was omitted on tag push, which prevented `Release Pre-built Binaries` and `Publish SDKs` from publishing artifacts).

## Changes in v1.2.1 (Phase 9 & Release Gate Hardening)

- **Rich `ON CONFLICT DO UPDATE` with `EXCLUDED.<col>` Expressions:** `INSERT ... ON CONFLICT DO UPDATE SET ...` now evaluates arbitrary expressions referencing both the existing row and `EXCLUDED.<col>` (`OnConflict::DoUpdateExprs`, e.g., `hits = hits + EXCLUDED.hits`) before type coercion, generated-column recomputation, `CHECK`/`UNIQUE`/`NOT NULL` checks, foreign-key cascades, and secondary/expression/partial index maintenance.
- **Compound Query Trailing Clauses & Views:** Added trailing `ORDER BY`, `LIMIT`, and `OFFSET` execution (`finalize_compound_rows`) to `UNION`, `UNION ALL`, `INTERSECT`, and `EXCEPT` queries, plus support for compound queries inside `CREATE VIEW`.
- **Pure Safe-Rust SQLite Date & Time Built-ins:** Implemented UTC civil date/time functions in `src/sql/datetime.rs` (`DATE`, `TIME`, `DATETIME`, `STRFTIME`, `UNIXEPOCH`, `JULIANDAY` with `'now'`, `'unixepoch'`, `'start of day|month|year'`, and `±N` unit modifiers) alongside `CURRENT_DATE`, `CURRENT_TIME`, and `CURRENT_TIMESTAMP` expressions.
- **Release Preflight & SDK Publishing Fix:** Updated `scripts/check-release-version.py` so `--tag vX.Y.Z` and `refs/tags/v*` CI runs fail fast if `docs/releases/vX.Y.Z.md` is missing, and cleaned up GitHub Release polling in `.github/workflows/publish-sdks.yml` (`gh release view --json isDraft`).

## Included from v1.2.0 (Phase 8 & Modular Refactor)

- Added `INTERSECT` / `EXCEPT`, `CROSS JOIN`, `CASE WHEN`, `CAST(... AS ...)`, `GENERATED ALWAYS AS (...)` computed columns, expression indexes, `UPDATE ... SET col = <expr|subquery>`, multi-column `ORDER BY`, correlated/uncorrelated scalar subqueries, chained multi-table joins, `[NOT] EXISTS` / `[NOT] IN`, `USING INDEX UNION` for `OR` predicates, and scalar built-ins (`IIF`, `IFNULL`, `NULLIF`, `REPLACE`, `INSTR`, `LTRIM`, `RTRIM`, `TRIM`, `TYPEOF`, `FLOOR`, `CEIL`/`CEILING`, `SQRT`, `POWER`/`POW`, `MOD`, `HEX`).
- Converted remaining read-only B+Tree loops to zero-copy `scan_with_ref(...)`, split `src/bin/tapirus/` and `src/sql/executor/` into focused submodules, and synchronized security documentation (`SECURITY.md`, threat model, and external audit RFP).

## Release checks

Source validation passes before tagging `v1.2.1`, including workspace formatting, strict Clippy (`-D warnings`), Rust core + edition profiles + `fault-injection` recovery + `tapirus-micro`, WASM (`@tapirus/wasm` and `@tapirus/wasm-lite`), TLA+ TLC2 crash-safety checks, OSV dependency advisory checks, and `scripts/check-release-version.py --tag v1.2.1`.

The tag-triggered release workflow (`release.yml`), crates.io publication (`tapirus`, `tapirus-micro`, `tapirus-ffi`, `tapirus-wasm`), PyPI (`tapirus`), and npm (`tapirus`, `@tapirus/wasm`, `@tapirus/wasm-lite`) are synchronized at version `1.2.1`.

TapirusDB supports a documented SQL subset and selected vector, graph and JSON APIs. This release does not imply full SQL or openCypher conformance, a general latency guarantee, a security certification or a managed service SLA.
