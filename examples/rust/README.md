# Rust examples

These Rust programs demonstrate selected APIs in the repository. They do not establish full SQL compatibility, cross-model transaction atomicity, crash safety, or performance. Older snippets may need to be updated for the current API.

Start with the tested, minimal quickstart in the [root README](../../README.md). Check each example against the current source and use disposable files until close/reopen and recovery behavior for the operations you need has been verified.
