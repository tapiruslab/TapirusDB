# Examples

These examples are exploratory programs, not product certification, compatibility tests, or benchmark evidence. Some older examples predate the current API and may use unsupported SQL or integration paths.

Before running an example:

1. Read its source and compare every API call with the current crate or SDK documentation.
2. Use disposable data until write, close, reopen, and recovery behavior are verified for your target.
3. Treat timing, memory, confidence, and retrieval values as demo output unless a reproducible benchmark defines and validates them.

The current Rust quickstart and implementation limits are in the [root README](../README.md). The audit findings and regression scope are in [the 15 October 2026 report](../audit/LAPORAN_AUDIT_TAPIRUSDB_2026-10-15.audit.md).
